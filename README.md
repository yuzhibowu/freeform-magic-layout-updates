# Freeform神奇排布

这是公开下载与自动更新仓库，仅包含签名安装包及版本信息；源码未公开。

[下载最新版本](https://github.com/yuzhibowu/freeform-magic-layout-updates/releases/latest)

下载 ZIP，解压后把“Freeform神奇排布.app”放入“应用程序”。每台电脑首次安装带更新功能的版本后，后续可通过软件更新。右键菜单可“检查更新…”或设置“自动下载并安装更新”。自动检查周期为四小时。

支持 Apple 芯片 Mac、macOS 13 及以上。需要系统 Python/Apple 命令行工具。应用使用固定本地签名，尚未做 Apple Developer ID 公证；首次运行如有系统拦截，请在“隐私与安全性”允许打开。

在无边记或 Keynote 选择对象并按 ⌘C，打开面板，采用排布，再回到原应用按 ⌘V。Keynote 图片排布超过幻灯片宽度时整体等比缩小；高度不限制。

自动更新基于 Sparkle。更新包使用 Ed25519 签名，并在解压前验证。固定应用签名用于保持应用身份；权限是否保留仍取决于系统状态。安装目录需要管理员权限时，macOS 可能要求输入密码。
